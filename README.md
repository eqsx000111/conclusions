# 📄 NDT Welding Report Generator

Десктопное приложение на Python для автоматической генерации комплектов отчетной документации по неразрушающему контролю (НК) сварных соединений (ВИК, РК, УЗК). Программа автоматизирует подстановку данных в шаблоны Microsoft Word (`.docx`), избавляя инженеров от рутинной работы и ошибок при заполнении журналов и заключений.

---

## 🚀 Основные возможности

- **Пакетная генерация:** Создание полного комплекта документов (ВИК, РК, УЗК) для конкретного стыка по одному нажатию.
- **Интеграция с MS Word (`.docx`):** Безопасный поиск и замена тегов (`{{JOINT}}`, `{{DATE}}`, `{{LAB_CERT}}` и др.) без повреждения таблиц, стилей, рамок и изображений.
- **Гибкая настройка дефектов (РК):** Интерактивная карта дефектов радиографического контроля с автоматическим расчетом интервалов и итогового заключения.
- **База специалистов:** Управление списком аттестованных инженеров (НАКС) с автоматической привязкой их удостоверений к выбранному методу контроля.
- **Конфигурация и персистентность:** Сохранение путей к шаблонам, рабочей директории и выбранных параметров в локальный файл `inspectors_config.json`.
- **Современный UI:** Интерфейс на базе библиотеки **CustomTkinter** с поддержкой тем оформления.

## 🛠 Технологии
Python 3.10+

python-docx — парсинг, изменение и генерация документов Microsoft Word.

## ⚙️ Установка и запуск
Клонируйте репозиторий:
```Bash
git clone [https://github.com/eqsx1/conclusions.git](https://github.com/eqsx1/conclusions.git)
cd название_репозитория
```
Создайте и активируйте виртуальное окружение:
```Bash
python3 -m venv venv
source venv/bin/activate  # Для macOS / Linux
# или venv\Scripts\activate для Windows
```
Установите зависимости:
```Bash
pip install -r requirements.txt
```
Запустите приложение:
```Bash
python3 -m app.main
```
💡 Поддерживаемые теги шаблонов (.docx)
В ваших шаблонах Word вы можете использовать следующие теги, которые программа заменит автоматически:
- {{JOINT}} — номер сварного стыка.
- {{DATE}} — дата оформления заключения.
- {{LAB_CERT}} — свидетельство об аттестации лаборатории НК.
- {{INSPECTOR_VIK}}, {{CERT_VIK}} — ФИО и удостоверение инспектора ВИК.
- {{INSPECTOR_RK}}, {{CERT_RK}} — ФИО и удостоверение инспектора РК.
- {{INSPECTOR_UZK}}, {{CERT_UZK}} — ФИО и удостоверение инспектора УЗК.
- Специфичные теги интервалов и дефектов для радиографии ({{0-300_cord}}, {{summary_concl}} и т.д.).
